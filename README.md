# Building Regulations Atlas

A web-based interactive map showcasing building regulation data across Sub-Saharan African countries, developed by the World Bank Group and GFDRR.

## Overview

The Building Regulations Atlas collates data from several World Bank Group resources on topics related to planning, design, and building control regulations and aspects of the wider building regulatory environment in selected cities and countries.

## Features

### Interactive Map
- **26 Sub-Saharan African countries** with clickable markers
- **Color-coded by dataset coverage**:
  - Dark blue: B-READY + BRR Report data
  - Light blue: B-READY data only
  - Gray: No data available
- Hover tooltips with country names
- Click to open detailed country profile

### Topic Filters
- **Planning and Zoning**
- **Building Design** (with sub-topic checkboxes): General Provisions, Building Classification, Structural Resilience, Fire Safety, Green Buildings, Universal Accessibility, Services
- **Materials**
- **Compliance Mechanisms** (with sub-topic checkboxes): Building Control, Transparency, Dispute Resolution, Professional Registration

### Country Profiles
- Key facts: Region, Income Group, Data Points
- Collapsible sections organized by topic
- "See Full Data" toggle for filtered vs. complete view

### Data Export
- CSV Download
- Excel Download
- Print/PDF
